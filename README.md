# YouTube 双语字幕 + 自动跳广告:零依赖浏览器扩展

看 YouTube 视频时,自动在画面下方显示 **英文原文 + 中文翻译** 双语字幕,广告自动快进跳过。
翻译用 **YouTube 内置机器翻译**(CC 菜单"自动翻译"的服务端版本):零 GPU、不用装任何东西、
不需要 API Key、不引入任何第三方服务。

```
YouTube 播放器字幕轨 ──> 扩展拦截 timedtext(英文原文)
                        └─> 同一 URL 补 tlang=zh-Hans 再请求 ──> 服务端译好的整条中文轨 ──> 双语显示
```

- 中文**即时显示**:整条翻译轨一次拿到,进度条拖到哪都有译文,没有预热
- **自动跳广告**:前贴/中插广告自动快进跳过(广告开始瞬间直接切回正片),弹窗可关
- **ASR 整句重组**:自动生成的字幕是滚动碎片("I never" → "I never thought…"),显示前先重组为完整句,不再一行一闪
- **双级翻译保险**:tlang 整轨翻译被风控的视频,自动回退到 Google 翻译免费端点(无需 Key,按行惰性翻译)
- 字幕条可**按住拖动**,位置自动记忆
- 播放广告期间双语字幕自动隐藏(广告字幕与正片时间轴冲突)
- 支持普通视频和 Shorts(Shorts 未深度测试)

## 安装

1. Chrome/Edge 打开 `chrome://extensions`(Edge 是 `edge://extensions`)
2. 打开右上角「**开发者模式**」→ 点「**加载已解压的扩展程序**」→ 选择本目录(`yt-bilingual-subtitles`)
3. 打开任意有英文字幕的 YouTube 视频即生效

> 需要 Chrome/Edge 111+(2023 年后版本都满足)。
> 访问 YouTube 需要你的代理,扩展本身不代理任何流量。

## 使用

- 字幕条:上排灰色小字英文原文,下排白色中文;按住可拖动
- 点扩展图标:
  - 启用/停用、显示/隐藏英文原文
  - 「隐藏 YouTube 原生 CC」默认开(避免和双语字幕重复),关掉就恢复原生字幕
  - 中文字号
  - 「重置字幕位置」
- 字幕轨默认不是英文时,扩展会自动切到英文轨(每视频一次,切换后旧轨字幕清空防止串台)

## 故障排查

| 现象 | 原因 / 处理 |
| --- | --- |
| 徽标「内置翻译不可用,使用备用翻译」 | tlang 被风控;已自动走 Google 免费端点,正常无需处理 |
| 徽标长期不消失 | 两个翻译源都不可达(网络/代理问题);检查能否打开 YouTube |
| 字幕完全不出现 | 该视频没有字幕轨(CC 按钮是灰的);换有字幕的视频 |

## 工作原理

```
yt-bilingual-subtitles/
├── manifest.json    MV3 清单(需要 Chrome/Edge 111+)
├── page-hook.js     注入页面 MAIN world,hook fetch/XHR 拦截 YouTube 自己的字幕请求并记下原始 URL;提供 seek 通道(跳广告用)
├── content.js       字幕接收、轨道语言纠偏(自动切英文轨)、tlang 翻译轨抓取与时间轴对齐、ASR 整句重组、
│                    备用翻译调度、跳广告、悬浮条渲染、拖动、广告期字幕隐藏
├── background.js    翻译兜底:tlang 被风控时代发 Google 免费端点(content script 受页面 CORS 限制)
├── lib.js           设置读写、视频页判定
├── overlay.css      悬浮字幕条样式
├── popup.html/js    设置弹窗(开关/字号)
├── icons/           图标
└── test/            E2E 截图 + 早期抓取实验
```

为什么用「拦截播放器自己的字幕请求」而不是直接抓字幕接口:YouTube 2024 年后对 timedtext 接口加了
PO Token 校验,脚本直接抓会返回空;而播放器自己发起的请求带完整凭证,扩展在页面里挂 hook 就能
100% 拿到和原生 CC 一样的数据。内置翻译同理:拿播放器用过的原始 URL 补 `tlang=zh-Hans` 再请求,
就能拿到服务端译好的整条中文轨。
